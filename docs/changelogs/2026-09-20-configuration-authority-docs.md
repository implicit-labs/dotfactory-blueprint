# Reconcile planning and placement authority

- Mark ADR-0040 and ADR-0041 Accepted after their implementations merged.
- Correct the verification-host and project/run guides: Planning may amend
  configurable implementation and verification fields only through exact plan
  and requirements approval.
- Preserve instance-owned credentials, registrations, billing identity, safety
  ceilings, pinned checks, and original admission history as immutable bounds.

This records existing runtime behavior. It introduces no new authority or
deployment change.
