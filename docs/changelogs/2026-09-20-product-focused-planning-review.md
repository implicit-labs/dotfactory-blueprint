# Product-focused planning review

- Choose routine verification from project defaults and scope; ask only about unresolved product decisions, material tradeoffs or user-owned blockers. Missing routine harness setup remains agent work, not a preference question.
- Lead the plan with product behavior and a short verification/evidence summary. Collapse technical requirements and changed project settings; omit unchanged settings noise.
- Preserve frozen reviews, unsafe-Markdown fallback and exact-version implementation approval. No semantic question filter silently removes unresolved decisions.
- Validate with focused Linear planning/conversation tests. Model compliance and device notification delivery still require live evidence; unit tests do not establish either.
