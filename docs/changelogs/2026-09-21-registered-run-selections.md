# Registered run selections

- Register named runner/model/reasoning/skill/capability/resource profiles at the instance ceiling; let projects and explicit runs select them globally or by work stage.
- Select only registered workflows. Freeze the resolved graph, placement, route settings and per-field origins at admission; reject changed selections on replay.
- Share resolution across preview, doctor, worker-check and runtime admission. Preserve Sol/medium as the Codex default.
- Bind selected graph digests to Linear statuses before projection, reusing verified mappings only when the status set is covered.
- Cover precedence, list clearing, invalid input, project isolation, fixture dispatch, restart and Linear binding variants with offline tests.
- Shared simulator/browser delegation, live model availability proof and native config content freezing remain outside this change.
